# Blood Donor Management System 🩸

A Django-based web application that helps users find blood donors by location and blood group.

## Features
- User Registration and Login
- Become a Blood Donor
- Find Donors by Location
- Search by Blood Group
- PostgreSQL Database Support

## Technologies Used
- Python
- Django
- PostgreSQL
- HTML
- CSS

## Installation

1. Clone the repository:
   `git clone https://github.com/jotkaur-6284/blood-donor-management.git`

2. Open the project folder:
   `cd blood-donor-management`

3. Create and activate a virtual environment.

4. Install dependencies:
   `pip install django psycopg2-binary`

5. Configure your database in `settings.py`.

6. Run migrations:
   `python manage.py migrate`

7. Start the server:
   `python manage.py runserver`
